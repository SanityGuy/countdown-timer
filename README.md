# ⏳ Countdown Timer
A modern and customizable countdown timer built using vanilla HTML, CSS, and JavaScript.

Supports multiple languages, accurate calendar-based countdown calculations, customizable target dates, and GitHub Pages deployment.

## ✨ Features

- Accurate calendar based countdown
- English, Indonesian, and Russian translations
- Change target date and time
- Responsive design
- Flatpickr date picker
- Live countdown updates
- Dynamic warning colors
- GitHub Pages ready
- Confetti celebration on completion

## 🛠 Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Flatpickr
- Canvas Confetti
- Font Awesome

## 🚀 Future Improvements

- More languages
- Better accessibility
- Theme customization
- URL countdown sharing
- Sound effects
- Animations
